# Testing

## До Реалізації

- [ ] Підтвердити технологію.
- [ ] Підтвердити тип скриптів.
- [ ] Підтвердити список секцій і кількість локацій.
- [ ] Підтвердити реальні або ліцензовані зображення.

## Після Скафолдингу

- [ ] Запустити `npm install`.
- [ ] Запустити `npm run dev`, якщо script існує.
- [ ] Запустити `npm run build`, якщо script існує.
- [ ] Перевірити, що початковий `src/index.html` не містить секцій або layout-коду, якщо ще не було запиту на реалізацію.

## Після Реалізації Секцій

- [ ] Desktop перевірка приблизно на 1440px.
- [ ] Tablet перевірка приблизно на 768px.
- [ ] Mobile перевірка приблизно на 390px.
- [ ] Сітка локацій переходить із 3 колонок у 1 колонку на малих екранах.
- [ ] Hero-текст читається поверх фонового фото.
- [ ] CTA-кнопки не переповнюють контейнер на mobile.
- [ ] Картки не мають обрізаного важливого тексту.
- [ ] Фото локацій не спотворюються.
- [ ] Фокус-стани для клавіатури видимі.
- [ ] Контраст основного тексту достатній.
- [ ] Відступи між секціями залишають сайт просторим, а не порожнім.
