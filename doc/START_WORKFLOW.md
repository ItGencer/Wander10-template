# Start Workflow

## Поточний Статус

Створено тільки інструкції. Проєктні файли для збірки, HTML, SCSS і JavaScript/TypeScript ще не створені.

## Потрібно Підтвердити Перед Скафолдингом

- Технологія: Webpack, React або Angular.
- Тип скриптів: JavaScript або TypeScript.
- Односторінковий чи багатосторінковий формат. За описом очікується one-page `[NEEDS CONFIRMATION]`.
- Остаточна мова інтерфейсу: українська або інша `[NEEDS CONFIRMATION]`.
- Список 10 локацій, якщо сайт справді має показувати Wander10 як добірку з десяти місць `[NEEDS CONFIRMATION]`.

## Якщо Буде Обрано Webpack

- Створити `package.json`, `webpack.config.js`, `postcss.config.js`.
- Створити `src/index.html` тільки як мінімальний пустий HTML-шаблон із правила `frontend-doc-agent`.
- Створити `src/index.js` або `src/index.ts` залежно від підтвердженого типу скриптів.
- Створити `src/style/` і `src/assets/`.
- Не додавати header, hero, картки, footer, SEO-метадані або стилі секцій до окремого запиту на реалізацію.

## Якщо Буде Обрано React

- Використати npm-based старт.
- Підтвердити build tool, наприклад Vite або інший варіант.
- Почати з мінімальної пустої оболонки.
- Не створювати компоненти секцій із загального дизайн-опису до окремого запиту.

## Якщо Буде Обрано Angular

- Використати Angular CLI тільки через npm/npx.
- Підтвердити routing і SCSS.
- Почати з мінімальної пустої оболонки.
- Не створювати компоненти секцій із загального дизайн-опису до окремого запиту.

## npm-Only Команди Для Майбутнього

- `npm install` - встановлення залежностей після скафолдингу.
- `npm run dev` - запуск dev server, якщо такий script буде доданий.
- `npm run build` - production-збірка, якщо такий script буде доданий.
