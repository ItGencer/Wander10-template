# Wander10 Template Instructions

Це папка інструкцій для майбутнього фронтенд-проєкту `Wander10 template`.

Поточний статус: створено тільки документацію в `doc/`. Вихідний код, стартові файли, секції сайту, стилі, скрипти та SEO-метадані ще не створювалися, бо користувач попросив: "Створи тільки інструкції більше не чого."

## Коротко Про Проєкт

- Назва сайту: Wander10.
- Тип: тревел-гід / landing page / шаблон сайту.
- Візуальний напрям: теплий, сучасний, заокруглений, просторий, туристично-затишний.
- Основна ідея: показати добірку топ-локацій для мандрівників, CTA-кнопки, короткі поради та простий футер.
- Цільова папка: `D:\IT Project\Frontend Developer\Project\Wander10 template`.

## Наступний Крок

Перед створенням будь-яких файлів у `src/` потрібно підтвердити технологію та тип скриптів. Якщо буде обрано Webpack, стартовий `src/index.html` має залишатися мінімальним пустим HTML-шаблоном до окремого запиту на реалізацію секцій.
